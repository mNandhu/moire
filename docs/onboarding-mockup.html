    Image folders

    Moiré indexes the images in these folders and reads the prompt saved in each one. New images are picked up as they're saved.

    The full path, such as ComfyUI's output folder. Subfolders are included.

    ComfyUI

    Both settings are optional. Skip this step if you don't use ComfyUI.

    Moiré queues prompts on this ComfyUI. What it makes lands in your output folder like any other image.

    Saved workflowsfor extraction rules

    Moiré groups images by the workflow that made them. Pick ComfyUI's workflows folder, usually ComfyUI\user\default\workflows, and each group is named after its file. Only each file's id, name and node types are kept.

    or drop the files here

    AI tagging

    Images are already tagged from their prompts, which covers search, filters and most of Moiré. The tagger adds tags for what is actually in each picture, which helps most with images saved without a prompt.

    About 0.6 images a second on CPU and 0.1 s an image on a GTX 1650. Your hardware will differ.
